# NVIDIA SEO Assistant

Local development integration, optional for the six core tools. The server uses NVIDIA's OpenAI-compatible chat-completions endpoint. Its catalog was successfully queried with the configured key. The default `nvidia/nemotron-3.5-lightning-30b-a3b` returned a nonempty live response with thinking disabled. This is a practical latency-oriented choice, not a benchmark-certified best SEO model. Alternatives `nvidia/nemotron-3-super-120b-a12b` and `moonshotai/kimi-k2.6` were present in the catalog but are not live-quality-certified here.

Open SEO Assistant at the bottom right of the app, select a website/model, and ask a question. Each request sends a bounded summary of the project built in server/ai.ts (projectContext): Search Console totals for the last 28 days against the 28 before, the top 30 queries with their previous position, top 15 pages, device and country split; backlink totals, link types, top anchors, strongest and riskiest referring domains; the latest mobile and desktop PageSpeed scores and Core Web Vitals; the latest completed audit with up to 30 findings, errors first; open issues; tracked keywords; and a list of data that is missing or not connected. No OAuth tokens, API keys or account passwords enter the model prompt. Stored model output is rendered as plain text, scoped by project ownership, and labeled AI-generated. Website evidence is treated as untrusted input. Review output before acting; prompt instructions cannot guarantee factual correctness or resistance to every injection attack.

Limits: 20 requests per project/day, 50 globally/day, 25-second provider timeout, 1,800 output tokens, 3,000-character questions, bounded context. Requests stop on errors or limits, with no automatic paid fallback. Suggestions do not supply live keyword search volumes, competitor research, verified backlink discovery or actual website edits. Existing measured reports remain separate.

Configure `NVIDIA_API_KEY` in ignored `.dev.vars` or server secrets. By default, only local localhost/127.0.0.1 deployments can use this provider. `NVIDIA_AI_PRODUCTION_ENABLED=true` is an explicit operator override, not evidence of commercial usage rights. NVIDIA's Developer Program FAQ describes free hosted access for prototyping and testing, not a promise of unlimited free production service. Review applicable terms before a production deployment: https://docs.api.nvidia.com/nim/docs/product.

Migration: `0003_ai_reports.sql`; conversations survive refresh in D1 and cascade with project deletion. Key values must not be committed or placed in VITE_ variables. Model availability and account limits may change.
